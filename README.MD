## Web 配置与运行

首次使用先安装依赖：

```bash
python3 -m pip install -r requirements.txt
```

在项目目录执行：

```bash
python3 config_web.py
```

浏览器打开 <http://127.0.0.1:11181>（局域网访问时使用运行主机的实际 IP），填写 `config.py` 中的配置，点击“保存配置”后即可点击“启动程序”。页面会实时显示 `main.py` 的运行日志，也可以点击“停止程序”。

账号、密码和课程 ID 在页面中分别填写。密码输入框不会回显已保存密码，保存时写入本地密文；留空会保留原密码。

控制台默认监听 `0.0.0.0`，可从局域网访问。如需指定其他监听地址：

```bash
python3 config_web.py --host 0.0.0.0 --port 11181
```
